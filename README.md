# ⚡ JamberTech Image Studio

**Ultra-fast AI image generation** powered by [Z-Image-Turbo](https://huggingface.co/Tongyi-MAI/Z-Image-Turbo) — generating stunning images in just **8 steps**.

## Features
- 🚀 **Ultra-fast** — only 8 DiT forward passes needed
- 🎨 **High quality** — up to 2048×2048 resolution
- 🌱 **Reproducible** — seed control for consistent results
- 🤖 **MCP-compatible** — use as an AI agent tool
- ⚡ **Free GPU** — powered by HuggingFace ZeroGPU (A10G)

## Model
- **Base:** [Tongyi-MAI/Z-Image-Turbo](https://huggingface.co/Tongyi-MAI/Z-Image-Turbo)
- **License:** Apache 2.0
- **Parameters:** ~6.15B
- **Guidance Scale:** 0.0 (CFG-free distilled model)
